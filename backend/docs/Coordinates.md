# Coordinate System

GML files may coordinate values that contain values expressed as **Easting and Northing values** in metres using the **British National Grid coordinate system** (also known as OSGB36 or EPSG:27700), which is the standard spatial reference system used by Ordnance Survey and HM Land Registry for mapping geographic data in Great Britain.

We need to convert this to Latitude and Longitude values using package like **proj4**.
